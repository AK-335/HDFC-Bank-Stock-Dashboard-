HDFC Bank Stock Dashboard 📊

An interactive stock market dashboard built to analyze HDFC Bank (HDFCBANK) stock performance. The dashboard provides a clear view of historical price trends, trading activity, and key market indicators to help understand the stock's performance over time.
Key Features
- 📈 Historical stock price visualization
- 💰 Open, High, Low, and Close prices
- 📊 Trading volume analysis
- 📅 Date-wise stock performance
- 🔍 Interactive data exploration
- 📉 Trend analysis through charts
